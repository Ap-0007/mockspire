# Code of Conduct

## Our Pledge

We are committed to making Mockspire a welcoming, respectful, and inclusive project for everyone.

We welcome contributions from people of all experience levels and backgrounds. Whether you are making your first open-source contribution or are an experienced developer, you are expected to treat others with respect.

## Expected Behavior

Contributors and maintainers are expected to:

- Be respectful and professional.
- Welcome newcomers and help them when possible.
- Give constructive and specific feedback.
- Focus on ideas and code rather than individuals.
- Communicate clearly and respectfully.
- Respect different opinions and approaches.
- Keep discussions relevant to the project.
- Accept constructive criticism gracefully.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment, discrimination, or personal attacks.
- Insulting, threatening, or deliberately disrespectful behavior.
- Trolling or intentionally disrupting discussions.
- Publishing someone's private information without permission.
- Unwelcome sexual or inappropriate content.
- Spam or malicious contributions.
- Any other behavior that could reasonably make the project unsafe or unwelcoming.

## Contributions

All contributions should follow the project's `CONTRIBUTING.md` guidelines.

Pull requests, issues, reviews, and discussions should remain constructive and focused on improving Mockspire.

Maintainers may request changes, close issues, or reject contributions that do not follow the project's guidelines or code of conduct.

## Reporting Issues

If you experience or observe unacceptable behavior, please contact the project maintainer through their GitHub profile or use GitHub's available private reporting mechanisms when appropriate.

Please do not create a public issue for sensitive or private concerns.

## Enforcement

Maintainers are responsible for interpreting and enforcing this Code of Conduct.

Depending on the severity of a violation, maintainers may:

- Ask the person to stop the behavior.
- Remove inappropriate comments or content.
- Close issues or discussions.
- Reject or remove contributions.
- Temporarily restrict participation.
- Permanently restrict participation in the project.

Enforcement decisions will be made fairly and with the goal of maintaining a respectful and productive community.

## Scope

This Code of Conduct applies to all project spaces, including:

- GitHub issues
- Pull requests
- Discussions
- Code reviews
- Project-related communication

## Acknowledgment

By participating in the Mockspire community, you agree to follow this Code of Conduct and help maintain a respectful environment for everyone.
